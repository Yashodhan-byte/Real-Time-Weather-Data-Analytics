# Power BI & Tableau Integration Guide - Real-Time Weather Data Analytics

This guide provides instructions for **Student 3 (Visualization & Reporting)** to connect Power BI or Tableau to the Hive/Spark SQL data outputs.

---

## 1. Data Connection Options

### Option A: Direct Import via Spark SQL / Hive ODBC Connector (Production Setup)
1. In Power BI Desktop, click **Get Data** -> **More...** -> **Database** -> **Apache Spark** or **Hive LLAP**.
2. Enter your Spark SQL Thrift Server Host (`localhost:10000` or server IP).
3. Select **Data Connectivity mode**:
   - **Import**: Recommended for fast offline reporting and complex DAX measures.
   - **DirectQuery**: Recommended for real-time live-updating dashboards.
4. Select tables: `weather_db.daily_analytics`, `weather_db.raw_weather`, `weather_db.regional_analytics`.

---

### Option B: Local File Connection (CSV/Parquet Export)
1. Open Power BI Desktop -> Click **Get Data** -> **Text/CSV** or **Folder**.
2. Browse to the output folder generated by Student 2:
   - `data/processed/daily_analytics.csv`
   - `data/processed/anomaly_analytics.csv`
   - `data/processed/regional_analytics.csv`

---

## 2. Power BI DAX Measures & Calculations

Create the following calculated measures in Power BI:

### A. Temperature Z-Score Anomaly Indicator
```dax
Z_Score_Category = 
IF(
    [Z_Score] > 2.0, "Extreme Heatwave",
    IF([Z_Score] < -2.0, "Extreme Cold Snap", "Normal")
)
```

### B. Dynamic 7-Day Moving Average DAX Formula
```dax
DAX_Moving_Avg_7D = 
CALCULATE(
    AVERAGE(daily_analytics[avg_temp]),
    DATESINPERIOD(
        daily_analytics[date],
        LASTDATE(daily_analytics[date]),
        -7,
        DAY
    )
)
```

### C. Extreme Anomaly Count
```dax
Total_Anomalies = 
CALCULATE(
    COUNT(anomaly_analytics[anomaly_status]),
    anomaly_analytics[anomaly_status] <> "NORMAL"
)
```

## 3. Recommended Dashboard Visual Layout

1. **Top KPI Cards**:
   - Global Mean Temperature (°C)
   - Total Monitored Cities & Regions
   - Active Temperature Anomalies (Heatwaves & Cold Snaps)
   - Total Cumulative Precipitation (mm)

2. **Line Chart (Time Series)**:
   - **X-Axis**: Date
   - **Y-Axis**: `avg_temp`, `moving_avg_7d`, `moving_avg_30d`
   - **Legend**: City Filter (Tokyo, London, New York, Sydney, Cairo, Mumbai, São Paulo)

3. **Scatter Plot (Anomaly Detection Matrix)**:
   - **X-Axis**: Date / Hour
   - **Y-Axis**: Temperature (°C)
   - **Color**: Anomaly Status (`EXTREME HEATWAVE` = Red, `EXTREME COLD SNAP` = Blue, `NORMAL` = Dark Slate)

4. **Clustered Bar Chart (Regional Comparison)**:
   - **Axis**: Region (Asia, Europe, North America, Oceania, Africa, South America)
   - **Values**: Region Avg Temp, Region Avg Humidity
