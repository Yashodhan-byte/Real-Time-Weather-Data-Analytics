🏗️ End-to-End Big Data Architecture Flow

Stage 1: Ingestion
Open-Meteo REST Stream
Fetches 22 Japanese station nodes hourly data via Python requests.
Stage 2: Storage
Hive HDFS Partition Warehouse
Hierarchical partitions: data/hdfs_hive/raw_weather/region=.../year=.../month=.../
Stage 3: Analytics
Apache Spark SQL Engine
PySpark Window functions compute rolling 7d/30d moving averages & Z-scores.
Stage 4: BI & Web UI
Power BI & Command Dashboard
Serves processed Parquet/CSV tables directly to interactive Command Center & Power BI.

Hive External Table DDL Schema (hive_schema.sql):

CREATE EXTERNAL TABLE IF NOT EXISTS weather_db.raw_weather (
    city STRING, prefecture STRING, country STRING, latitude DOUBLE, longitude DOUBLE,
    timestamp STRING, date STRING, hour INT, temperature DOUBLE,
    humidity DOUBLE, wind_speed DOUBLE, precipitation DOUBLE, surface_pressure DOUBLE
)
PARTITIONED BY (region STRING, year INT, month STRING)
STORED AS TEXTFILE;
